# v1.3.1

Activates GPT-5.5 and GPT-5.5 Pro.

```bash
npm i -g codex-multi-auth
```

They're now tried first on Codex runtimes that support them, with deterministic fallback preserved for older runtimes and accounts without access.

**Fallback got stricter.** Requests were falling back to `gpt-5.4` more eagerly than they should have. It now only happens after a real upstream "unsupported model" or "no access" response, rather than on any error that looked vaguely related.

## Hardening

A broad pass across request handling, auth, account management, recovery, storage, settings, UI, and shutdown — covering rate-limit backoff, token redaction, SSE buffering, account removal, manual-paste state, import size caps, OAuth state checks, retry writes, and cleanup idempotency.
