# v2.1.5

Removes auto-update, and isolates Codex's SQLite state during rotation.

```bash
npm i -g codex-multi-auth
```

## No more auto-updating

The package no longer updates itself or mutates the global install. Startup now just prints a notice when a newer version exists, and you decide when to upgrade.

Update checks are also detached from the Codex launch path, so they can't slow down or interfere with starting a session.

## Runtime isolation

Codex's goal, log, and state SQLite files are now isolated per runtime session. Your config, sessions, plugins, skills, and multi-auth state are shared as before — only the volatile SQLite files are separated.

That path is hardened for the messy cases: large or locked database files, leftover directories from a previous run, Windows sidecar files, and path casing differences.

## Fix

`thread/goal/get` returns `{ "goal": null }` for recoverable upstream errors and exhausted pools, instead of surfacing noisy goal-read errors in the Codex TUI.
