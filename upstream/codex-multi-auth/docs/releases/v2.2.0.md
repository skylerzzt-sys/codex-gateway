# v2.2.0

Adds the `mcodex` launcher, plus a security pass over the proxy and storage.

```bash
npm i -g codex-multi-auth
```

## `mcodex`

A launcher that shows you what you're about to run before it starts — model, reasoning effort, working directory, active account, quota usage, plan, and how stale the cache is.

```bash
mcodex                          # status line, then Codex
mcodex --tmux                   # inside tmux with mouse scrollback
mcodex --tmux --live-accounts   # adds a live account pane
mcodex --monitor                # monitor only
```

The status line reads local cache and account state — **it never calls OpenAI on launch**. Quota refreshes in the background only when stale (10 minutes by default, `CODEX_MULTI_AUTH_STATUS_QUOTA_REFRESH_INTERVAL_MS`), behind a lock. Turn it off with `CODEX_MULTI_AUTH_STATUSLINE=0`.

`--monitor` and `--live-accounts` fail fast if `watch` isn't installed, rather than spawning a broken pane.

## Security

**The rotation proxy and local bridge now bind loopback-only, with no opt-out**, and no longer forward your inbound credentials (`authorization`, `x-api-key`, `cookie`, `proxy-authorization`) upstream.

Other hardening in the same pass:

- Cached Codex instructions are SHA-256 verified, so a tampered cache is never served or used to drive a conditional `304`.
- Stored ids are validated before being used to build file paths — an id like `../poison` is quarantined rather than followed.
- The account store is atomic and self-healing: checksummed write-ahead log, write-to-temp-and-rename, and retries across the transient Windows lock errors.
- Runtime observability is written owner-only on POSIX.
- Tokens and emails are masked across logs, the debug bundle, and status output. The debug bundle also redacts your home directory prefix and strips config credentials.

## Quota

An unsupported Codex model is now detected from the upstream error shape properly, so you get a readable "Codex unavailable" note across `best`, `forecast`, `report`, and live checks instead of raw upstream text. A genuinely transient failure still surfaces as the real error rather than hiding behind that note.

## CLI

- `status` and `list` gained `--json`, with a stable shape whether or not you have accounts configured.
- `switch <index>` now requires a real integer instead of silently truncating a float.
