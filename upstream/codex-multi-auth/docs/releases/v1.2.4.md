# v1.2.4

Storage recovery fixes.

```bash
npm i -g codex-multi-auth
```

- **A failed backup could report success.** Recovery returned a successful result even when persisting the backup had failed, so you'd be told your accounts were recovered when they weren't.
- Restored retry coverage for transient Windows `EBUSY` locks on flagged-account backup and legacy reads, which a previous change had dropped.
