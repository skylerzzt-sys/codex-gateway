# v0.1.1

Fixes OAuth callback failures and a clean-install crash.

```bash
npm i -g codex-multi-auth
```

- **The OAuth callback is now pinned to `127.0.0.1:1455`** rather than `localhost`. On machines where `localhost` resolves to IPv6 first, the callback never arrived.
- **A clean global install could fail on startup.** The `codex` bin wrapper now lazy-loads the auth runtime instead of pulling it in at module load.

## Storage

- Account emails dedupe case-insensitively now.
- Per-project account storage is shared across linked Git worktrees, so switching branches doesn't look like a different project.
- Windows cleanup retries through `EBUSY`/`EPERM`/`ENOTEMPTY` locks.

## CLI

The settings hub was split out of `codex-manager.ts` into five focused modules. The `Q` hotkey now cancels without saving, which is what people expected it to do.
