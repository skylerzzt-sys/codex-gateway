# v1.2.7

Works with Homebrew and release-binary installs of Codex, not just npm.

```bash
npm i -g codex-multi-auth
```

The wrapper only knew how to find Codex when it was installed through npm. It now discovers the official CLI on your `PATH`, so Homebrew and downloaded-binary installs work too.

That required telling JavaScript entrypoints apart from native executables — get it wrong and you either get a self-wrapper loop on POSIX, or the wrong `codex.exe` taking precedence on Windows. Both are handled.
