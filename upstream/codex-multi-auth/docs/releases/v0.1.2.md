# v0.1.2

Hardens account backups against interrupted writes.

```bash
npm i -g codex-multi-auth
```

- Rotating backup recovery across `.bak`, `.bak.1`, and `.bak.2` with deterministic fallback ordering.
- Backup rotation stages then commits, so a failure mid-write can't leave a partially rewritten history chain.
- Retry and backoff for staged renames and transient Windows file locks (`EPERM`, `EBUSY`, `EAGAIN`).
- **Startup now cleans up orphaned staging files** from interrupted writes. Those could otherwise sit around holding token material.
- Windows home-directory resolution now tries `USERPROFILE` → `HOME` → `HOMEDRIVE`+`HOMEPATH` → `homedir()`, handling `HOMEPATH` values with no leading slash.
