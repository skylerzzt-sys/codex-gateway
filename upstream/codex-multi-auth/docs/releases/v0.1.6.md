# v0.1.6

Fixes account storage being reset on update, and auth writes landing in the wrong profile.

```bash
npm i -g codex-multi-auth
```

- **Updates could reset your accounts.** Runtime path selection didn't handle storage that was only reachable through recovery artifacts, so an update looked like a fresh install.
- **Codex CLI sync wrote to the wrong directory.** Default paths now follow `CODEX_HOME`, so auth writes go to the profile you're actually using.
- Backup discovery can now restore `openai-codex-accounts.json` from non-standard backup filenames automatically.
- Account switches fail fast when the required Codex auth write doesn't complete, rather than reporting success.
