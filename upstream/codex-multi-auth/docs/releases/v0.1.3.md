# v0.1.3

Fixes `switch` reporting failure when it actually worked.

```bash
npm i -g codex-multi-auth
```

`switch <index>` was reporting a failure when Codex host-state sync was unavailable — which is normal on newer Codex runtimes that don't keep the JSON auth artifacts it was looking for. The local switch had succeeded; only the optional sync hadn't.

Local switching now succeeds regardless, and the messaging distinguishes the two so you can tell which part actually happened.
