# v0.1.9

Fixes business accounts overwriting each other.

```bash
npm i -g codex-multi-auth
```

Separate seats on the same business workspace share an `accountId`. Login, refresh, and restore were all treating that id as unique, so signing into one seat overwrote its siblings — especially on accounts with no email attached.

Identity matching is now consistent across runtime login, CLI recovery, storage normalisation, import, entitlement tracking, and refresh handling, so distinct seats stay distinct.
