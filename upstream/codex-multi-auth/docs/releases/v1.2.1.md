# v1.2.1

Adds `forecast --explain`, plus fixes and docs.

```bash
npm i -g codex-multi-auth
```

## New

```bash
codex-multi-auth forecast --explain
```

Shows the reasoning behind a forecast rather than just its conclusion.

## Fixes

- Wrapper version flags (`--version` and friends) behaved incorrectly.
- Exporting storage with an empty account pool didn't work properly.
- GPT-5 model routing realigned with current OpenAI defaults.

## Docs and packaging

Beginner onboarding was simplified and command guidance refreshed, plus maintainer runbooks added. The package also gained subpath exports with tighter coverage of what's actually shipped.
