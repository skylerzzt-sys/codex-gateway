# v2.0.2

Adds device-code login for headless machines.

```bash
codex-multi-auth login --device-auth
```

For servers and remote shells where you can't open a browser locally. It polls for completion and exchanges the code with PKCE through the Codex device redirect.

Tokens persist through the normal account storage, Codex CLI sync, and active-account state, exactly like a browser login.

`--device-auth` can't be combined with `--manual` or `--no-browser` — those are different transports and combining them is a mistake, so it's rejected rather than silently ignoring one. The browser-first, manual-paste, and no-browser paths are unchanged.

Device-code poll responses are kept out of logs and account storage.
