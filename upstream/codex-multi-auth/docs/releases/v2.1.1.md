# v2.1.1

Fixes local commands falling through to the official Codex CLI.

```bash
npm i -g codex-multi-auth
```

`usage`, `account`, `budget`, `bridge`, `integrations`, `models`, and `monitor` were being forwarded to official Codex instead of being handled locally — so they either failed or did something unexpected. Routing is restored.

Also fixed: `bridge token list --json` returned invalid JSON when the token store was empty, and was including token hashes in its output. Neither now.
