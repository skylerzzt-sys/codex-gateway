# v0.1.8

Adds Codex CLI sync, and fixes deleted accounts coming back.

```bash
npm i -g codex-multi-auth
```

**Cleared accounts could revive themselves.** If the initial delete partially failed, recovery paths would restore the accounts you'd deliberately cleared. An intentional clear now suppresses those paths.

## Codex sync

Target detection, import adapters, named backup wrappers, and sync orchestration around the existing storage model. Codex CLI state stays mirror-only — we read it and write to it, but this package's storage remains the source of truth.
