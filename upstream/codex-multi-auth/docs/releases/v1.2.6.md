# v1.2.6

Fixes usage counters not moving for forwarded commands.

```bash
npm i -g codex-multi-auth
```

Requests you made through wrapped non-auth commands — a real `codex exec`, say — weren't incrementing the runtime counters, so `status` and `report --json` showed nothing happening even while you were actively using it.

They now count. The wrapper only records metrics when the child process left the snapshot unchanged, so nothing gets counted twice when the plugin has already recorded it.
