# v1.2.3

Fixes cooldowns not persisting, and wrapper config rewriting.

```bash
npm i -g codex-multi-auth
```

- **Usage-limit cooldowns weren't sticking** across account state, fallback `429` handling, and quota scheduling — and the fix keeps secondary quota state instead of dropping it.
- The wrapper's compatibility path now rewrites unsupported reasoning-effort config correctly, and staged auth state syncs back before cleanup rather than being lost.
- Fixed ready-first account ordering, including a menu auto-refresh race that could skip a refresh that had just been requested.
