# v1.2.0

Adds manual login for headless environments.

```bash
codex-multi-auth login --manual
```

For machines where a browser can't be launched, or where the local callback listener won't work — you complete the sign-in elsewhere and paste the result back.

Explicit no-browser environment toggles are honoured properly now, and manual mode skips waiting for a callback that's never coming.

## Rotation

- Proxy-compatible upstream transport, so this works behind a corporate proxy.
- Accounts whose workspace is disabled or expired now auto-rotate away instead of failing repeatedly.
- Onboarding can restore from your most recent saved backup.
- **Selected workspace routing survives retries.** A retry or fallback used to collapse back to the token-derived identity, quietly moving you to a different workspace than the one you'd chosen.
