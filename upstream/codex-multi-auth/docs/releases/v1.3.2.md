# v1.3.2

Fixes interactive Codex sessions launched through the wrapper.

```bash
npm i -g codex-multi-auth
```

Forwarded runs were capturing output for every session, which broke interactive TTY use — the terminal needs its stdio passed through, not intercepted.

TTY-attached sessions now inherit terminal stdio directly. Non-TTY runs still capture output, because that's what lets unsupported-model fallback inspect the error and retry.

Also: a wrapper launch failure now goes through the normal clean-failure path even when `spawn()` throws synchronously, which is what happens on Windows.
