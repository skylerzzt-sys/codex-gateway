# v0.1.7

The first consolidated release of `codex-multi-auth`.

```bash
npm i -g codex-multi-auth
```

Brings the runtime, TUI, account management, and documentation together into one package, completing the migration to a Codex-only tool.

## Storage recovery

Rotating backup fallback, plus automatic promotion of a real backup when primary storage turns out to contain fixture data rather than your accounts.

## Windows

Hardened global command routing across `codex.bat`, `codex.cmd`, and `codex.ps1`, including replacing stock shims and resolving the shim from the invocation path first.

## Also fixed

Codex CLI account switching stabilised, and storage identity fixed across worktree branch changes.
