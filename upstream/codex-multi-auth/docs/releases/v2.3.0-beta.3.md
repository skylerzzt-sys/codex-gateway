# v2.3.0-beta.3

```bash
npm i -g codex-multi-auth@beta
```

Includes everything from beta.2 and the drain-first feature from beta.0.

## Fixed

**Streaming stalled forever for slow clients.** Stream forwarding never checked whether the client socket was keeping up, so a slow reader caused unbounded buffering in-process. It now waits for the socket to drain before pulling the next chunk upstream.

**Account deduplication needed more than one pass.** Merging duplicates by one identity tier could install an account that then duplicated an *earlier* survivor through a different tier — an email-tier merge producing an entry whose account id and refresh token already matched something above it. Dedup now loops until the list stops changing. Each pass removes at least one entry, so it always terminates.

## Security

Atomic writes now use `crypto.randomBytes` for temporary filenames instead of `Math.random()`, so a local attacker who sees one staging path can't predict the next.

## Cleanup

852 lines of dead code removed — seven modules with no remaining importers — plus unused exports pruned and a dead-code analyser wired in to keep it that way.

Two startup guards and one config abort now throw typed errors with machine-readable fields, so callers can branch on the error type instead of matching message text. The messages themselves are unchanged.
