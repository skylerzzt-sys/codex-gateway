# v2.0.1

Runtime rotation is now on by default.

```bash
npm i -g codex-multi-auth
```

The rotation proxy from v2.0.0 was opt-in. It's now enabled out of the box, so failover across your accounts works without any setup.

To turn it off:

```bash
codex-multi-auth rotation disable
```

Or set `codexRuntimeRotationProxy=false`, or `CODEX_MULTI_AUTH_RUNTIME_ROTATION_PROXY=0`.

## Also

- Install and update now self-heal the packaged Codex app bind and launcher routing, so an upgrade doesn't leave them pointing at the wrong place.
- Live quota probes and fallback models updated to current selectors, including `gpt-5.3-codex` and `gpt-5.5`.
