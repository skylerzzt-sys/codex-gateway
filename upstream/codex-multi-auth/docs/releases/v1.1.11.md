# v1.1.11

Fixes quota data mixing between accounts that share an email.

```bash
npm i -g codex-multi-auth
```

Two accounts on the same email in different workspaces were colliding on the same quota-cache key, so one account's quota data overwrote the other's.

Two related fixes: live quota fallback state stays distinct after `check` and `fix` refresh the shared identity fields, and a failed cache save no longer mutates the in-memory cache — previously a save failure could corrupt the data you already had loaded.
