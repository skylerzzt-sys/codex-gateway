# v1.2.5

Stops runaway retries across your whole account pool, and adds observability.

```bash
npm i -g codex-multi-auth
```

## Retry behaviour

**Whole-pool replay is off by default now.** When every account was rate-limited, a single prompt could replay across the entire pool — burning through accounts that were already known to be limited. Outbound attempts per prompt are also capped.

Retry and failover are tightened for `429`s, upstream `5xx` bursts, empty responses, stream replay, quota deferral, cooldown drift, and usage-limit `404`s.

## Visibility

`status` and `report --json` now show runtime counters, cooldown state, why an account was selected, and storage health.

`report` also gained controls so you can inspect state without hammering every account:

```bash
codex-multi-auth report --cached-only
codex-multi-auth report --max-accounts 3
codex-multi-auth report --max-probes 5
```

## Windows and storage

Storage-health inspection, atomic cache and snapshot writes, quieter write-ahead-log recovery checks, retried cleanup through transient `EBUSY`/`EPERM` locks, and safer live-sync and session-affinity writes.
