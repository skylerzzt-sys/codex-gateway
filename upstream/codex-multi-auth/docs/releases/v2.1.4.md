# v2.1.4

Two fixes for the Codex TUI goal proxy.

```bash
npm i -g codex-multi-auth
```

- The goal proxy now handles snake-case `thread_id` request bodies, and returns a local fallback when a goal read is blocked.
- **Disabled accounts stayed disabled.** Workspace-disabled and deactivated accounts were being hidden by the goal fallback rather than remaining visible and disabled at runtime.
