# v2.1.2

Stops this package hijacking the `codex` command.

```bash
npm i -g codex-multi-auth
```

We were registering a global `codex` bin, which collided with the official Codex distributions — npm, native, and Homebrew. Whichever installed last won, which is not a good way to decide what `codex` means on your machine.

That bin is gone. The two commands you use are unchanged:

- **`codex-multi-auth`** — account management
- **`codex-multi-auth-codex`** — the forwarding wrapper
