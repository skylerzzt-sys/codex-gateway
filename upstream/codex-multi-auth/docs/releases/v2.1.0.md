# v2.1.0

Adds local usage tracking, spending guards, and an optional API bridge.

```bash
npm i -g codex-multi-auth
```

## Usage and budgets

A local-only JSONL usage ledger, plus account policy metadata, routing profiles, and budget guards. Two new commands:

```bash
codex-multi-auth usage      # what you've spent
codex-multi-auth monitor    # watch it live
```

Everything stays on your machine — nothing is reported anywhere.

## Capability matrix

Model and account capability views, with policy evaluated *before* an account is selected rather than after a request fails.

## Local bridge (optional)

A loopback-only HTTP bridge exposing `/health`, `/v1/models`, and `/v1/responses`, with hashed client-token storage. Off unless you turn it on.

## Also

- `rotation reset-rate-limits` clears stale runtime timers when the pool gets stuck.
- Account emails are masked in proactive-refresh logging.
