# v1.2.2

Fixes refreshed tokens being lost when the account pool is written.

```bash
npm i -g codex-multi-auth
```

A token refreshed just before its expiry could be overwritten by a concurrent account-pool write, throwing away the fresh token and leaving the account with the expired one.

Account identity reconciliation was also tightened across refresh outcomes, runtime tracking, model-family selection, and expired-cache hydration — so a refreshed token reliably lands on the account it belongs to.

## Account health

Realigned how account health is handled across the board: healing after a success, guardian penalties, circuit-breaker penalties, reason-scoped rate limiting, and stale cooldown metadata.
