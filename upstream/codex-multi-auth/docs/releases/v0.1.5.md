# v0.1.5

Fixes a Windows crash on wrapper shutdown.

```bash
npm i -g codex-multi-auth
```

`codex auth` could trigger a `UV_HANDLE_CLOSING` assertion after the command had already finished — the work was done, but you got a crash instead of a clean exit.

## Model matrix

The test harness was updated for current Codex CLI invocation semantics (`exec` plus JSON mode), with Windows `.cmd` wrappers resolved to their script entry for stable argument passing. Success and failure classification is tighter, which cuts false negatives that came from guessing based on output text.
