# v2.1.12

Fixes Codex hooks being lost when runtime rotation is active.

```bash
npm i -g codex-multi-auth
```

## What was wrong

Runtime rotation runs Codex against a temporary copy of your config. Your `[hooks.state.*]` blocks weren't being carried across, so hooks configured in your real `config.toml` silently didn't run.

## What's fixed

Those blocks are now mirrored into the runtime config when the hook key points at your own `hooks.json`, with the key rewritten to the copy's path.

The rewrite preserves CRLF line endings and full table bodies, and leaves unrelated hook entries, alternate hook files, and existing entries alone.
