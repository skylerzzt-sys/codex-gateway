# v2.3.0-beta.2

```bash
npm i -g codex-multi-auth@beta
```

The drain-first feature from beta.0 is unchanged; the pointer bug below is fixed.

## Fixed

**Drain-first mode advanced its pointer when it shouldn't.** In `sequential` mode, a transient fallback to a secondary account permanently moved the primary — breaking the whole point of draining one account before moving on. A guard that already existed on one code path was missing from the other.

**An expired token could be forwarded after a refresh.** When the refresh succeeded but the account couldn't be found in storage afterwards, the fallback used the *old* token rather than the freshly issued one. That produced a downstream `401` and wrongly triggered invalidation-cooldown logic on a healthy account.

**Flagged-account restore dropped workspace data.** Restoring a flagged account rebuilt it from a hardcoded field list that omitted `workspaces`, `currentWorkspaceIndex`, `accessToken`, and `expiresAt` — so a multi-workspace account permanently lost its workspace list on a flag-and-restore round trip.

**A transient disk failure wiped every account's quota data.** When reloading the quota cache came back empty — which is what happens on *any* read failure, since it returns empty rather than throwing — only the current run's entries were written back, discarding everyone else's still-valid data.

## Security

- Atomic writes use `crypto.randomBytes` for temporary filenames instead of `Math.random()`.
- CI workflow steps are pinned to exact commit SHAs rather than floating tags.
- Response headers under our own `x-codex-multi-auth-account-*` namespace are blocked by prefix, so a header added there later is blocked by default rather than leaking until someone remembers to update a list.
- Fixed a timeout that could report a stall as a success: cancelling a stream reader inside the timeout handler could settle the race with a clean "done" before the rejection landed.

## Internals

`codex-manager.ts` went from 2,266 lines to 690 (-82%), and the rotation proxy was split up similarly. All import cycles were eliminated and a lint rule now enforces that. The published package also dropped JS source maps, and the config JSON schema is now generated from its Zod source with a drift guard so the two can't diverge.
