# v2.0.0

Adds the runtime rotation proxy — failover between accounts without restarting your session.

```bash
npm i -g codex-multi-auth
```

## What's new

Before this, switching accounts meant restarting Codex. The rotation proxy sits between Codex and OpenAI and fails over mid-session when an account hits a quota limit, needs a token refresh, or the network hiccups.

It works for both the CLI and the Codex app, and it's localhost-only with an authenticated local client key.

```bash
codex-multi-auth rotation enable      # opt in
codex-multi-auth rotation status
codex-multi-auth rotation bind-app    # route the Codex app through it
codex-multi-auth rotation unbind-app  # and back
```

App binding is reversible — `unbind-app` restores your config.

## Under it

Sessions run against a shadow `CODEX_HOME` with refreshed state synced back on exit, so rotation doesn't disturb your real Codex state.

## Fix

The proxy no longer leaves a stale `content-encoding` header on responses it decoded.
