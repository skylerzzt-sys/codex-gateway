# v1.3.0

Adds diagnostics for "why did it pick that account?"

```bash
npm i -g codex-multi-auth
```

## New commands

```bash
codex-multi-auth why-selected      # explains the account choice
codex-multi-auth verify --paths    # checks path safety
```

`why-selected` is the one people asked for — when rotation picks an account you didn't expect, this tells you what went into that decision.

## Concurrency

A feature-flagged routing mutex for safer concurrent account selection. Off by default; the existing behaviour is unchanged unless you turn it on.

## Hardening

A post-audit pass covering OAuth URL redaction, a single source of truth for the redirect URI, hybrid-selector null handling, short-`429` retry ordering, active-pointer normalisation, atomic recovery writes, storage reset ordering, config-conflict surfacing, and malformed SSE warnings.

Storage JSON parsing moved onto schema-validated boundaries, and the settings hub was split into focused modules.
