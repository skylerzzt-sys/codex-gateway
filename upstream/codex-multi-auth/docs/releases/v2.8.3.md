# v2.8.3

A small follow-up to v2.8.2 for quota display. Nothing to migrate.

```bash
npm i -g codex-multi-auth
```

## What changed

Some accounts report a quota window with no label, no duration, and no reset time. Compact summaries were rendering those as a permanent `100%`, which looked like real information and wasn't.

Those windows are now hidden. Full windows that *do* carry useful data still show, and the dashboard no longer falls back to an empty `live session OK ()` when both windows turn out to be uninformative.
