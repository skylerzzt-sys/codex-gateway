# v0.1.4

Fixes stuck token refreshes and unclear switch failures.

```bash
npm i -g codex-multi-auth
```

- **Refresh lanes could get stuck.** Token normalisation and stale/timeout recovery in the refresh queue are hardened, which cuts both wedged lanes and duplicate refresh churn.
- `switch <index>` keeps local account selection deterministic, and reports a sync failure clearly instead of leaving you guessing whether the switch worked.
