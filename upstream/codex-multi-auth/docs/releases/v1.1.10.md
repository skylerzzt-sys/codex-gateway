# v1.1.10

Adds `best`, and fixes workspace bindings being lost on refresh.

```bash
npm i -g codex-multi-auth
```

## New

```bash
codex-multi-auth best
```

Switches your active account to whichever the forecast says is best right now.

## Fixes

- **Workspace bindings didn't survive a token refresh.** Accounts now handle workspaces that change after login, and keep their binding through refresh flows.
- Rotated access, refresh, and ID tokens stay aligned through the already-best and switch paths — previously they could drift apart, leaving an account with a mismatched set.
- Fixed install instructions that could cause an npm `EEXIST` collision with an official Codex install.
