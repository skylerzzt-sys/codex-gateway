# v2.2.1

Fixes `mcodex` on Windows, plus a batch of concurrency and validation bugs.

```bash
npm i -g codex-multi-auth
```

## Launcher

**`mcodex` died on Windows** with `HCS_E_SERVICE_NOT_AVAILABLE` when a WSL stub shadowed git-bash. It shipped as a bash script registered as a Windows bin, which was never going to work reliably.

It's now a Node script with no bash dependency on the default path. `tmux` and `watch` are invoked as argument arrays rather than shell strings, and degrade gracefully when they're not installed.

Two smaller launcher fixes: it now resolves through npm-created symlinks properly, and relays `SIGTERM`/`SIGINT` to the child so it's never orphaned.

## Auth

- **Parallel logins could cross-wire.** OAuth state lived on the shared server instance rather than per-login, so two logins at once could bind each other's callback code and state.
- The local token store's read-modify-write is now serialised, with a wider retry set for transient Windows file locks.

## Rotation

- **Closed a selection race** under `routingMutex="enabled"` — selection and cursor commit now happen in one lock acquisition.
- **A request with no model was billed to the wrong family.** It fell into the general `gpt-5.5` bucket instead of the codex one, which threw off rotation, cooldown, and budget accounting.
- Inbound `cookie` and `proxy-authorization` headers are stripped on both egress paths, and auth is checked before path and method so you get a `401` rather than a `404`.

## Storage

- **Fixed a deadlock.** Recovering flagged storage inside a held lock tried to re-acquire the global mutex, wedging every save after it.
- **A `doctor` restore erased your manual pin.** The pin and affinity counter weren't carried through the transaction clone.
- Secret directories are created `0o700`, fractional indices are floored, and `NaN` is coerced rather than propagating.

## Quota and forecast

- `gpt-5.5` is now the default probe model, with the older chain preserved as fallback.
- **Accounts that can't use Codex are labelled "signed in", not "working"** — they're not the same thing, and calling them working was misleading. Live check now counts `Codex available` / `signed in only` / `need re-login` separately.
- Policy-blocked and token-exhausted accounts are excluded from recommendations.
- A failed live check that happens to carry a quota percentage now renders red instead of green.

## CLI

- **`--model` no longer eats the next flag.** A flag-like or whitespace-only value after `--model` is rejected rather than consumed.
- Non-integer `workspace` and `switch` indices are rejected instead of silently truncated.
